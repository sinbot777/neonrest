Staff roles

Permissions are checked on the server for each request. Roles add capabilities; editing a Vibe is assigned separately per Vibe. This page reviews assignments and the current policy.

Owner

Reserved for the site founder. All current staff capabilities; protected from moderation.

Admin

Staff oversight, account and post moderation, Vibe approvals, and moderator assignment.

Manager

Vibe approvals, account and post moderation, and review history.

Moderator

User lookup, bans, restrictions, post hiding and restoration, and review history.

Vibe editor

Only assigned Vibes and their CSS. No sitewide moderation access.
