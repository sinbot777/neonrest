How to use this page

Review a request’s status, redacted path, account ID and network address together. A 404 can be an intentional privacy response; a scanning label is a heuristic, not proof of abuse. Do not block an address solely because it returned an error.

Restriction, retention and recovery rules

IP addresses can be shared by a household, school or mobile network and can change. Prefer the existing account moderation tools for a known account. Use a short network restriction for repeated abuse, record a factual reason without private details, and release it promptly if it affects other people.

Restrictions apply only to the selected environment. They expire automatically after 1 hour, 24 hours or 7 days. Your current address cannot be blocked here. Verified active owner/admin sessions can reach the site to recover from a restriction. Privacy and Terms remain available; direct static/media requests still use existing content permissions.

Private event records have a 30-day retention target, pruned on subsequent activity. Existing account preservation blockers retain associated account/IP security evidence until resolved; retaining a record does not extend a restriction. Shared-IP association is an investigative lead, not proof of identity. Records are capped at 20,000 rows. Log views, restriction creation and release are audited. No passwords, cookies, authenticator codes, request bodies or raw referring URLs are recorded. Security collection applies independently of optional visitor statistics and DNT/GPC. Only owner/admin accounts with recent authentication and 2FA may use this page. IPs are not included in the statistics dashboard or its CSV.
