Search discovery

Aggregate query reports imported by the owner/admin from Google Search Console or Bing Webmaster Tools. These are provider-reported searches, never linked to a Neonrest account, IP address or browser session. Provider privacy filtering omits some queries; visible query totals need not equal all search clicks. Imports are operator supplied, not independently verified or automatically synced.

The date filter includes only reports whose entire date range fits inside the selection. The traffic filter does not apply: providers cannot split Neonrest guests, members or staff. Each report uses its provider's reporting timezone, not necessarily UTC. Reports are shown separately; overlapping ranges for the same provider are rejected to avoid double counting. Each report displays and exports its top 100 query rows.

Connect providers and import a query report
  1. Verify https://www.neonrest.com/ in Google Search Console and Bing Webmaster Tools. Ownership verification is separate from AdSense verification.
  2. Open Search performance, select an exact date range and export the aggregate Queries/Keywords table as an English CSV. Use Google's Queries.csv from the downloaded ZIP. Do not paste individual visitor records, account data or analytics credentials.
  3. Select the provider and enter those exact dates below. Paste the CSV including its header. Supported columns: Top queries / Query / Keyword(s), Clicks, Impressions, and optional Position / Average position. CTR is calculated from the counts.
  4. Import up to 2,000 rows / 1 MiB. The original file is not stored. Reimporting the identical provider and dates atomically replaces that snapshot. Other overlapping dates are rejected. Stored reports expire when their start date leaves the retained 90-day window; total storage is capped at 10,000 query rows.
