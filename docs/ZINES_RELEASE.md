# Collaborative Zines release status

Status: 4 November 2026. Available in Sandbox; Production release pending.

Zines supports Standard, Custom and Advanced toolsets; inline and wrapped artwork; linked stories; styles and master elements; single-page, two-page and continuous reading; grouped atmosphere presets; sharing previews; and reading, booklet and mini-eight PDF output.

The latest mobile fix keeps Custom's Save/Cancel buttons visible while its options scroll. A confirmed 390 × 740 browser check passed page save/reload, retained inline artwork, Custom Save persistence, Cancel and Escape, with no horizontal overflow. Reader checks passed single-page display, a standalone cover and interior spread, and all eight pages in continuous scroll.

The follow-up validation passed 470 application checks for each environment candidate, 245 security checks, and the authoring, sharing, appearance, release-guard, folding, sizing and anchored-artwork suites. Counts overlap and must not be added as unique tests.

The current distributable is being refreshed to include the mobile fix and updated validation. The storage blocker has been cleared. Production has not been deployed. Actual Facebook preview rendering remains a check after the public release.

Advanced has substantial composition tools but is not yet equivalent to a mature professional publishing suite. Rich typography, live linked-text reflow, professional prepress, live coediting and other planned capabilities remain incomplete.
